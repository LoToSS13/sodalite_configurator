## Расхождения внутри самой библиотеки

- Icon Button S: описание для разработки задаёт hit44 / surface38 / icon20, старый нарисованный вариант содержит surface42 / icon24. В коде использовано описание для разработки. Исходный вариант Figma не исправлялся.
- Context Menu: описание задаёт ширину256 и radius20; старый контейнер имеет250 и radius32. В коде выбрана спецификация для разработки.
- Card: отдельный заголовок18/26 с tracking0 отличается от общего стиля Headline S18/24. Для заголовков карточек создана локальная функция `sodaliteCardTitleStyle`.
- `get_motion_context` вернул пустой список timeline-узлов. Параметры нажатия прочитаны из описаний компонентов, а не выдуманы из статического изображения. Spring реализован через Flutter `SpringDescription.withDurationAndBounce`.

## Реализация и границы проверки

После перезагрузки проверены сворачивание/раскрытие клавишей Space и копирование JSON с уведомлением «JSON скопирован». При проверке меню/диалога работали Enter/Escape.
